# Mission: CS 374 Algorithms (pass the class)

## Why
Pass CS 374. Midterm 2 is close and I can't start problems yet. I need enough real understanding to earn rubric points on every exam problem, then keep building for the final.

## Success looks like
- Given a new DP problem, write all the recipe steps: English definition, recurrence + base case, answer call, table + fill order, running time.
- Given a "get from here to there" problem, build the graph and name the algorithm (BFS, DFS, topological sort, Dijkstra).
- Use binary search (and binary search on the answer) when a problem calls for it.

## Constraints
- Very little time before Midterm 2 (date not yet given).
- Teach in baby-sized bites: one idea at a time, plain words, then practice right away.
- Order: DP first, then graphs, then binary search.

## Out of scope
- Regular languages and automata (Midterm 1 material) for now.
- Writing formal correctness proofs beyond what the rubric needs.
