DP recipe

Write every step on exams. Each step is worth rubric points, even if your recurrence is wrong.

The steps

StepWrite down
1aEnglish definition of what the function returns. Not how it is computed.
1bRecurrence, with base cases.
1cWhich call answers the original problem, for example MaxSum(1).
2aRange of every parameter, for example 1 ≤ i ≤ n+2.
2bData structure: an array named after the function.
2c–dWhat each entry reads, and a fill order that computes those first.
2fRunning time = (number of entries) × (time per entry).

From final-review.typ, lec13_10_08_26.typ, rubrics/dp.pdf, and Erickson, Chapter 3.

Finding the recurrence

  1. Make one decision about position i.
  2. List every option.
  3. For each option, ask: "after this choice, where am I allowed to continue?"
  4. Combine the options with max, min, or OR.

Template: take it or skip it

MaxSum(i) = best sum picked from A[i..n], no two neighbours
MaxSum(i) = 0                                     if i > n
MaxSum(i) = max( MaxSum(i+1),  A[i] + MaxSum(i+2) )  otherwise
Answer: MaxSum(1) · array MaxSum[1..n+2] · fill i from n down to 1 · O(n)
